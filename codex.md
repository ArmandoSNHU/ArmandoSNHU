# Codex Maintenance Guide

## Purpose

This repository is the special GitHub profile repository for `ArmandoSNHU`. The root `README.md` appears on the GitHub profile page and should stay concise, professional, and portfolio-focused.

## Editing Rules

- Keep the profile factual and current.
- Do not claim production experience, certifications, employers, or degrees unless the user explicitly confirms them.
- Prefer project outcomes and demonstrated skills over hype.
- Keep links pointed at public repositories and `https://gomezdev.tech`.
- Avoid emojis and decorative clutter in the profile README.
- Do not include private contact information unless the user asks for it.

## Update Checklist

When adding or changing featured projects:

1. Confirm the repository is public and has a strong README.
2. Verify the project link works.
3. Keep the table to five to seven high-signal projects.
4. Mention the demonstrated skill, not just the technology.
5. Make sure each listed repo has a `codex.md` handoff file.

## Recommended Verification

Review Markdown rendering locally or on GitHub after changes. Check all links in the featured project table before publishing.
